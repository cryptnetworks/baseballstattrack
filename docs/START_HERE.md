# Start here

Baseball Stat Track is a scorekeeping and statistics platform for coaches and
scorekeepers. It records the events that happened in a game and derives player,
team, game, and season results from those events.

## Choose what you want to do

- To install the supported production stack, use
  [Production installation](PRODUCTION_INSTALLATION.md).
- To score games and use product features, use
  [Product guides](PRODUCT_GUIDES.md).
- To understand exactly how outcomes and statistics are determined, use
  [Rules and calculations](RULES_AND_CALCULATIONS.md).
- To understand the architectural and product decisions behind the production
  system, use [Design choices](DESIGN_CHOICES.md).
- To connect external services or configure Discord, use
  [Integrations guide](INTEGRATIONS_GUIDE.md).
- To deploy and maintain a secure production system, use
  [Operations and security](OPERATIONS_AND_SECURITY.md).

## How this Wiki is organized

The sidebar stays intentionally small. Each section above is a curated hub that
links to focused reference pages. Use the page search when you already know a
specific topic.

Documentation is maintained in the repository `docs/` directory. The public
Wiki is generated from those files; direct Wiki edits are not authoritative.
The Wiki contains production operations, product guidance, integrations,
architectural design choices, and calculation rules. Development workflow and
project-planning material remains repository-only.
